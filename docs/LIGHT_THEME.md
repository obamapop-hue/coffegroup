# 밝은 테마와 삼성 인터넷의 강제 다크 모드

확인일: 2026-10-21 (한국 시각).

영차는 공통 `base.html`의 `color-scheme: only light`, `supported-color-schemes: light`, 흰 `theme-color`와 CSS의 `color-scheme: only light`, 흰 `html`/`body` 배경을 사용한다. 기기 설정에 따라 사이트가 자체 다크 테마로 전환되는 코드는 없다.

사용자는 카카오톡과 크롬에서는 흰 배경이지만 삼성 인터넷에서는 검은 배경이라고 확인했다. 삼성 인터넷은 자체 웹페이지 강제 다크 모드에서 사이트의 `color-scheme` 선언을 무시하는 사례가 있다. `!important`나 같은 메타 선언을 반복하는 것만으로 이 브라우저 설정을 확실히 막을 수 있다고 보고하지 않는다. 검증되지 않은 색 반전·텍스트 채우기·이미지 배경 편법도 전 브라우저 해결책으로 배포하지 않는다.

참고 사례:

- https://github.com/mdn/browser-compat-data/issues/17408
- https://github.com/mdn/browser-compat-data/issues/29347

기기의 검정 테마를 유지하면서 사이트 지정 색을 보려면 삼성 인터넷의 설정 → 웹페이지 보기 및 스크롤 → 다크 모드에서 웹 콘텐츠 강제 다크 모드를 해제한다. 설정 이름과 위치는 삼성 인터넷 버전에 따라 다를 수 있다. 실기기에서 설정 항목을 찾기 어려우면 버전과 설정 화면을 확인한다.

일반 시스템 다크 모드와 브라우저의 웹페이지 강제 색 변환은 구분한다. Chromium의 자동 다크 모드 검증은 삼성 인터넷 실기기 검증을 대신하지 않는다. Safari도 WebKit 모사 또는 UA 변경을 실제 iPhone Safari 검수라고 부르지 않는다. 이 작업 환경에는 삼성 인터넷과 iPhone Safari 실기기가 없으므로 이들에서 해결됐다고 보고할 수 없다.

실제 HTTPS에 배포된 메타와 해시된 CSS의 밝은 테마·흰 배경 설정을 재확인했다. 이번 점검에서는 기존 사이트 동작과 배포를 변경하지 않았다.
