# 운영자 회원 관리 — 2026-10-26

사용자가 운영자에게 회원의 가입·탈퇴 여부가 보이지 않는 문제의 수정을 요청했다.
구현과 로컬 검증을 마쳤으며 실제 Google 배포는 아직이다.

## 화면

운영자 페이지의 **회원 관리 · 가입·탈퇴 확인**에서 표로 확인한다.
경로는 `/accounts/operator/members/`이며 운영자만 접근할 수 있다.
표에는 회원 관리용 번호, 닉네임, 가입/탈퇴/이용 중지 상태, 현재 이용 권한과 연결
카페, 가입 시각, 탈퇴 시각과 카카오 연결 상태/해제 확인 시각이 표시된다.
닉네임·회원 번호 검색, 가입/탈퇴 필터와 25행 단위 페이지 이동을 제공한다.
모바일에서는 표 안에서 좌우로 이동하고 앞쪽 번호·닉네임을 고정한다.
목록에서 계정을 강제 탈퇴시키는 기능은 추가하지 않았다. 후속 요청으로
[주문 이용 정지·해제](MEMBER_ORDER_SUSPENSION.md)를 추가했다. 로그인 권한은 유지한다.

## 이력과 기존 회원

별도 MembershipRecord에 닉네임·기존 가입 시각을 저장한다. 가입이나 로그인 때
새 이력을 중복 생성하지 않고 같은 계정의 닉네임만 갱신한다. 기존 회원은 DB 구조
갱신 때 실제 date_joined를 이용해 이관한다. 이전 웹 버전이 배포 교체 중에 만든
계정은 목록의 내부 동기화로 보완한다. 이 동기화는 계정/권한을 바꾸지 않는다.

탈퇴 때 이력의 계정 연결을 끊고 닉네임과 처리 시각을 남기는 작업을 기존 계정
삭제와 같은 DB 거래에서 처리한다. 실패하면 이력도 함께 되돌아가며 중복 요청으로
별도 탈퇴 이력이 늘지 않는다. 카카오 연결 해제 작업에 이력을 연결해, 로컬 탈퇴 후
외부 연결 해제 확인 전에는 ‘해제 대기’, 응답을 확인하면 ‘해제 완료’와 시각을 표시한다.
실제 해제 결과를 모르면 완료라고 표시하지 않는다. 재가입은 새 회원 번호의 새 이력이다.

이력에는 카카오 회원 구분 번호·계정 연결 코드·토큰·이메일·전화번호를 복사하지 않는다.
탈퇴 때 기존 로그인 계정과 연결 코드는 삭제하고, 카카오 회원 구분 번호는 기존대로
재시도 작업에만 임시 보관한 뒤 확인되면 제거한다. 보존된 닉네임 이력이 있으므로
‘모든 개인정보가 삭제됐다’고 안내하지 않는다. 탈퇴 전/완료 화면과 개인정보 초안에
이력 보관을 알렸다. 이 이력의 구체적인 보유·삭제 기준은 아직 확정하지 않았다.

기능 적용 전에 이미 삭제한 계정의 이름·가입/탈퇴 시각은 복원하지 않는다.
과거 자료가 없는 사람을 새 가입/탈퇴 이력으로 만들어 내지 않고 화면에 한계를 알린다.
기존 진행 중 주문·운영자 탈퇴 제한과 고정 주문의 SQL 수정 방지는 유지한다.

## 검증과 반영

기존 기능을 포함한 앱 검사 214개를 통과했다. 추가된 9개 검사는 기존 가입 시각·
권한·카페 표시, 탈퇴 대기/완료 이력, 재가입 분리, 중복/실패 시 이력 보존,
운영자 권한·캐시 금지·POST 차단, 검색/필터/페이지와 HTML 이스케이프,
기존 회원 이관·배포 중 누락 보완, 실제 allauth 콜백의 닉네임 갱신을 확인한다.

별도 로컬 DB/가짜 계정과 대체 Kakao 응답으로 Chromium 320/390/1440px에서
가입 목록 → 실제 CSRF 탈퇴 제출 → 같은 이력의 탈퇴/해제 완료 표시를 확인했다.
표 내부 가로 이동과 화면 전체의 가로 넘침 없음을 확인했다. 실제 Kakao 회원이나
Google 자료를 시험 삭제하지 않았다. DB 변경 누락·코드 형식·운영 파일 수집도 통과했다.

Google 반영은 기존 Cloud Shell의 일반 갱신 명령으로 진행한다. 기존 카카오 키·
운영자 권한·카페·메뉴·주문은 유지한다. 새 이력 표를 만들고 기존 회원을 이관한다.

```bash
git -C ~/yeongcha pull --ff-only && python3 ~/yeongcha/scripts/gcp_update_site.py
```

반영 뒤 운영자 페이지에서 본인/가입한 회원을 먼저 조회하고, 별도 회원의 실제
가입·탈퇴 시험 때 가입 상태 → 탈퇴 및 해제 확인 상태 변화를 확인한다.
이 변경만으로 개인정보 처리방침의 보관 근거나 8단계 전체 완료를 확정하지 않는다.
