# 회원의 주문 이용 정지 — 2026-10-26

사용자가 운영자 회원 관리에서 회원을 정지해 주문을 이용하지 못하게 요청했다.
기존 가입 조회가 가능하다는 사용자 확인을 받은 뒤 진행한 후속 기능이다.
구현·로컬 검증은 완료했으며 이 변경의 Google 반영은 아직이다.

## 운영자 사용법

회원 관리 표의 주문 이용 칸에서 **주문 정지 / 정지 해제** 버튼으로 설정한다.
주문 정지 회원만 조회하는 필터, 정지 계정 수와 최근 20개 처리 이력을 제공한다.
변경 후에도 검색·필터·페이지를 유지하며, caller의 외부 next 주소는 사용하지 않는다.
동일한 상태로 반복 요청하면 새 이력을 남기거나 반대 상태로 바꾸지 않는다.

이 기능은 User.ordering_suspended를 사용한다. is_active나 카카오 연결, 로그인 세션,
운영자·판매자 권한을 정지하는 기능과 분리했다. 운영자는 자신을 주문 정지해도
회원 관리에 접근해 해제할 수 있다. 기존 is_active=False 계정이나 탈퇴 계정은
이 버튼으로 다시 활성화하지 않는다.

## 차단 범위

정지된 현재 계정은 새 주문서 생성, 주문 추가·수정·항목 삭제·참여 마감·최종 전송을
이용할 수 없다. 버튼을 숨기거나 비활성화하는 것과 함께 서버와 서비스 계층에서
실제 DB 상태를 확인한다. 오래 열린 화면·이전 전송 토큰·낡은 User 객체로도 차단한다.
정지 회원이 만든 미전송 주문방의 공유 링크는 참여 불가로 표시하고 제출을 막는다.
로그인한 정지 회원이 다른 주문방에서 참여자로 제출하는 것도 차단한다.

주문 내역 조회, 문의, 탈퇴 준비, 미전송 주문서 전체 삭제와 카페 수락 전 취소는
유지한다. 카페의 이미 전송된 주문 접수·거절·메뉴 완료, 총무 알림과 5분/30분 기한
처리는 계속된다. 판매자 로그인/로그아웃 영업 규칙과 주문 원본 보호도 유지한다.
정지를 해제해도 주문방의 메뉴판·만료 시각을 바꾸거나 폐기된 방을 다시 열지 않는다.

비회원은 계정을 받지 않으므로 로그아웃한 사람을 특정해 차단하는 기능은 아니다.
탈퇴 후 재가입은 기존 설계처럼 새 회원이다. 탈퇴한 사람을 추적하기 위한 카카오 ID
보관·해시 차단 목록, 기기/IP 차단이나 비회원 로그인 강제는 추가하지 않았다.

## 저장·권한·동시 실행

운영자만 CSRF가 검증된 POST로 상태를 바꾼다. 서비스에서도 실제 운영자 권한과
대상 계정 상태를 다시 확인한다. 같은 계정 행을 잠가 상태 변경과 주문 처리를 순서대로
수행한다. 정지가 확정된 뒤 새 주문/전송이 시작되지 않도록 하고, 반대로 먼저 전송이
끝난 주문은 보존한다. 여러 회원을 확인하는 참여 요청은 회원 번호 순서로 잠근다.
읽기 전용 전송 미리보기는 주문서 조회의 기존 잠금 순서를 거스르지 않는다.

OrderRestrictionEvent에 대상 회원 이력 번호, 처리자 참조·닉네임, 정지/해제와 시각을
저장한다. 상태 변경과 이력 저장은 같은 DB 거래이며 실패하면 함께 되돌아간다.
카카오 회원 구분 번호·비밀키·전화번호를 복사하지 않는다. 개인정보 초안과 탈퇴 안내에
보관 범위를 추가했고, 별도 보유·삭제 기준이 법적으로 확정됐다고 안내하지 않는다.

## 검증과 반영

기존 기능과 신규 정지 검사 12개를 포함해 앱 226개가 통과했다. 운영자/CSRF 권한,
반복 요청, 권한 회수·이력 실패 시 되돌림, 자신 정지 후 관리 접근, 오래 열린 화면과
직접 서비스 호출 차단, 공유방·참여자 차단, 읽기/문의/취소/삭제/카페 처리 유지,
메뉴판·기한 보존, HTML 이스케이프와 정지/전송 동시 실행을 확인했다.

별도 로컬 DB와 가짜 회원·대체 Kakao 응답으로 Chromium 320/390/1440px에서 실제
CSRF 버튼 클릭 → 주문 비활성/요청 차단 → 해제 후 주문 복구 → 탈퇴 이력을 확인했다.
실제 Google 회원을 정지하거나 탈퇴시키지 않았다.

기존 Cloud Shell 일반 갱신 명령으로 반영한다. 기존 회원은 기본적으로 주문 가능하며
추가 카카오 키 설정은 필요하지 않다.

```bash
git -C ~/yeongcha pull --ff-only && python3 ~/yeongcha/scripts/gcp_update_site.py
```
