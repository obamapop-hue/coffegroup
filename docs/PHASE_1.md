# 1단계 결과 — 실행 기반

최초 검증일: 2026-10-20. 아래는 1단계 최초 완료 당시의 기록이다. 이후 Railway 테스트 배포와 화면 수정을 완료했고 사용자 승인으로 2단계를 진행했다. 현재 상태는 [테스트 배포 기록](TEST_DEPLOYMENT.md)과 [2단계 상태](PHASE_2.md)를 참고한다.

## 구현

- Python 3.12, Django 5.2 LTS, PostgreSQL 17 기반 프로젝트.
- `uv.lock`과 PostgreSQL 이미지 digest로 의존성 고정.
- 환경변수 기반 설정과 무작위 로컬 비밀값 생성. 기존 `.env`는 덮어쓰지 않으며 Git 제외·소유자 전용 권한 적용.
- 계정 확장용 `accounts.User`와 초기 마이그레이션. 실제 카카오 로그인·역할 부여는 미구현.
- 한국어 기본 메인 화면과 반응형 스타일. 총무·판매자·운영자 로그인 버튼은 준비 중이며 비활성화.
- 웹 응답 확인·DB 준비 상태 경로, 실제 PostgreSQL 쓰기·읽기 검증 명령.
- 다시 실행할 수 있는 설치 스크립트와 README.
- 클라우드 환경의 `install_script`·`start_skill` 초안에 설치·시작·준비 상태 확인 절차를 저장했다. 최초 저장 응답은 불확실했으나 재조회에서 두 필드와 초안 revision 1을 확인했다. 환경 공개·새 작업 복원까지 검증한 것은 아니다.

현재 화면은 기본 안내 화면이다. 비활성 로그인 버튼이나 서비스 흐름 소개를 실제 로그인·주문 기능 완료로 해석하지 않는다. 브라우저 검증은 데스크톱 Chromium의 화면 크기를 조정해 수행했으며 실제 iPhone·Android 실기기 검증은 아직 하지 않았다.

## 파일 위치

- `config/`: 환경 설정·URL·웹 서버 진입점.
- `accounts/`: 향후 카카오 계정 연결을 위한 사용자 모델 확장 지점.
- `core/`: 기본 화면·상태 확인·DB 검증 명령·테스트.
- `templates/`, `static/`: 화면과 스타일.
- `compose.yaml`: 로컬 PostgreSQL과 영속 데이터 볼륨.
- `scripts/`: 로컬 설정 생성과 재실행 가능한 개발 설치.
- `README.md`: 설치·실행·중지·검사 방법.

검증 스크린샷은 현재 클라우드 작업공간 `/workspace/artifacts/coffegroup-stage1/`에 있다. 저장소 소스나 외부 배포 주소가 아니다.

## 다음 단계의 범위

2단계는 실제 카카오 로그인, 한 회원의 여러 역할, 판매자 계정·카페 연결, 로그인 유지·로그아웃과 영업 상태, 역할별 접근 제한이다. 카카오 개발자 앱의 소유·설정과 실제 연동을 확인해야 한다. 앱 키·비밀값은 채팅이나 저장소에 넣지 않고 환경 설정으로 관리한다.

이번 단계에는 주문 기능·자동 거절·사이트 알림·앱 푸시를 포함하지 않았다. Apple APNs·Google FCM 결정과 5분 자동 거절 요구는 개발 계획에 유지한다.
