운영자 확인용 · 아직 공개하지 않은 초안

이 화면은 운영자만 볼 수 있어요. 보관 근거·기간과 실제 서버 기록 설정이 확정되지 않은 부분이 있어, 완성된 개인정보 처리방침으로 공개하지 않았어요.

탈퇴에 필요한 카카오 연결을 회원 정보 변경 없이 확인할 수 있어요.

운영 주체와 문의

운영 주체: 영차. 문의는 사이트의 문의하기에서 접수하고 답변을 확인할 수 있어요. 이메일이나 전화번호 입력을 요구하지 않아요.

회원 정보

카카오 회원 구분 번호와 닉네임, 가입·로그인 시각, 영차 계정 연결 코드와 권한을 저장해 같은 회원과 본인 주문을 확인해요. 카카오의 이메일·전화번호·프로필 사진·로그인 토큰은 회원 DB에 보관하지 않아요.

주문 정보

참여자가 입력한 이름(닉네임), 메뉴·옵션·수량·금액과 제출·수정·처리 이력을 저장해요. 판매자는 메뉴별 합계와 총무의 주문 당시 닉네임을 보고, 참여자별 이름과 총무의 전화번호는 볼 수 없어요.

운영자가 요청한 보관 방침은 과거 주문과 주문 당시 닉네임의 계속 보관이에요. 이를 일률적인 법정 의무라고 안내하지 않아요. 보관 목적·기간·근거와 개인정보 삭제 요청에 대한 처리 기준 확인이 남아 있어요.

문의 정보

제목·내용·답변·시각·처리 상태와 작성자 구분값을 보관해요. 답변이 끝난 날부터 1년이 지나면 문의와 답변을 함께 삭제해요. 추가 문의가 있으면 다음 답변 완료일부터 다시 계산해요. 답변 대기 중인 문의는 이 자동 삭제 대상에 포함하지 않아요.

탈퇴 처리

탈퇴하면 회원 정보와 계정 연결 코드를 삭제하고, 과거 주문과 계정의 연결을 끊어요. 주문 내용과 주문 당시 닉네임은 바꾸지 않아요. 다른 기기의 로그인도 사용할 수 없게 돼요.

카카오 연결 해제에 응답이 없으면 카카오 회원 구분 번호를 임시 보관하며 재시도하고, 확인되면 해당 번호를 삭제해요. 재시도 중에는 같은 계정의 재가입을 막아요. 카카오에서 직접 연결을 끊었을 때 영차가 통보를 받는 기능은 아직 없어요.

로그인 유지와 접속 기록

로그인 쿠키는 마지막 이용부터 최대 1년 동안 유지해요. 로그아웃하면 해당 브라우저의 로그인은 끝나요. 접속 오류를 확인하기 위한 IP·경로·시각 등의 서버 기록도 생겨요. Google 접속 기록의 실제 보관기간과 처리 위치는 추가 확인이 필요해요.

서버와 백업

Google Cloud를 이용해 웹과 DB를 서울 지역에서 운영해요. 자동 DB 백업은 최근 7개를 보관해요. 수동 백업의 삭제 기준과, 탈퇴한 정보가 백업 복구 때 되살아나지 않도록 처리하는 절차는 추가로 정리해야 해요.

남은 확인

주문 닉네임의 계속 보관 근거, 대기 문의·서버 기록·수동 백업의 보유와 삭제, Google 위탁·처리 위치 안내, 개인정보 권리 요청의 실제 처리 절차를 확정한 뒤 공개해요. 카카오 자체 동의 화면이 영차의 개인정보 안내 전체를 대신하지는 않아요.
